# LifeOS 🚀

A comprehensive personal productivity dashboard built with Next.js, React, Tailwind CSS, and Prisma.

## Features ✨

- **Habit Tracking**: Track daily habits, maintain streaks, and analyze completion history.
- **Goal Management**: Set actionable goals and track progress over time.
- **Daily Check-Ins**: Reflection tools and daily status logging.
- **Personal Analytics**: Visual breakdown of your productivity patterns.

## Tech Stack 🛠️

- **Framework**: [Next.js](https://nextjs.org/) (App Router)
- **Styling**: Tailwind CSS & shadcn/ui components
- **Database / ORM**: Prisma
- **Icons & UI**: Lucide React

## Getting Started 🏁

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run the development server:
   ```bash
   npm run dev
   ```

3. Open [http://localhost:3000](http://localhost:3000) in your browser.
