# Changelog

All notable changes to the **LifeOS** project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2026-07-26

### Added
- Added `CHANGELOG.md` to track project releases, maintenance logs, and feature development history.
- Verified TypeScript strict build validation and runtime health checks.

### Recent Enhancements (July 2026)
- **User Authentication**: Integrated NextAuth authentication flow and login page.
- **Dashboard & Habit Tools**: Added direct dashboard logging console, live habit stopwatch timer, partial habit credit tracking, and layout optimization.
- **Dark Mode & Control Scripts**: Implemented precision dark mode theme, stepper habit targets, hydration tracking widget, and simplified control scripts (`start.ps1`, `stop.ps1`).
- **Documentation**: Updated project architecture overview, setup guides, and feature breakdown in `README.md`.
